# Python Flask Calculator 🧮

A simple and user-friendly calculator web application built using **Python** and the **Flask** framework.

The application allows users to perform basic arithmetic operations through a web interface.

## 🚀 Features

* Addition
* Subtraction
* Multiplication
* Division
* User-friendly web interface
* Handles division by zero
* Responsive calculator layout

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **HTML5**
* **CSS3**
* **Jinja2**

## 🧮 Supported Operations

| Operation      | Symbol | Example     |
| -------------- | ------ | ----------- |
| Addition       | `+`    | 10 + 5 = 15 |
| Subtraction    | `-`    | 10 - 5 = 5  |
| Multiplication | `*`    | 10 * 5 = 50 |
| Division       | `/`    | 10 / 5 = 2  |

## 📦 Requirements

* Python 3.x
* Flask

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/harsha-vardhini123/Calculator_using_python_with_flask.git
```

### 2. Navigate to the Project Folder

```bash
cd Calculator_using_python_with_flask
```

### 3. Create a Virtual Environment

```bash
python -m venv env
```

### 4. Activate the Virtual Environment

**Windows PowerShell:**

```powershell
.\env\Scripts\Activate.ps1
```

**Windows Command Prompt:**

```cmd
env\Scripts\activate
```

### 5. Install Flask

```bash
pip install flask
```

Or install all project dependencies from `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 6. Run the Flask Application

```bash
python app.py
```

The application will start on the local Flask server.

Open your browser and visit:

```text
http://127.0.0.1:5000/
```

You can also use:

```text
http://localhost:5000/
```

### 7. Stop the Application

To stop the Flask server, press:

```text
Ctrl + C
```
